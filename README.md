# How to work
Get in the folder "notebooks" in any of the files you want to edit, click "Open in Colab" and edit whatever you want. 
Then click save, you see a cloud icon in colab as usual.

Then you will see that github is now updated. niceee
However if u now click "Open in Colab" again you won't see your updated version because it take a few minutes to github to update.
